# Sources and licensing notes

## Sources

- Vitsoe, "Dieter Rams: ten principles for good design" —
  https://www.vitsoe.com/gb/about/good-design (the principles' headings and
  Rams' own short explanations; this skill paraphrases rather than quotes
  them).
- Dieter Rams, *Weniger, aber besser / Less but Better*, 1995.
- Interaction Design Foundation, "Dieter Rams: 10 Timeless Commandments for
  Good Design" — https://ixdf.org/literature/article/dieter-rams-10-timeless-commandments-for-good-design
- tommyjepsen/awesome-ux-skills, `dieter-rams-principles.md` — the idea of
  per-principle smells and a rated review format.
- WCAG 2.2: contrast 4.5:1 text / 3:1 UI components (1.4.3, 1.4.11),
  target size (2.5.8), focus visible (2.4.7).

## Licensing and naming

- The ten principle headings are widely cited; explanations here are
  original paraphrases. Don't paste Vitsoe's text into products.
- The palette is inspired by, not copied from, any manufacturer's products;
  color values are not protectable. Don't use manufacturer names or
  trademarks (e.g. "Braun") in token names, product names or UI; describing
  the inspiration in documentation is fine.
- IBM Plex Sans / Mono: SIL Open Font License 1.1 — self-hosting and
  embedding allowed; keep the license file with the fonts.
- Lucide icons: ISC license — keep the notice.
- Akzidenz-Grotesk, Helvetica and similar commercial typefaces are **not**
  part of this system; don't embed them without a license.
